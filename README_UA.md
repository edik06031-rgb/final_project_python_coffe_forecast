# **Прогноз продажу кави**

Проєкт машинного навчання для прогнозування місячного доходу кафе за допомогою лінійної регресії в Python.

Повний аналітичний робочий процес, який демонструє, як історичні дані продажів можна перетворити на бізнес‑прогноз доходу. Проєкт охоплює візуалізацію даних, тренування моделі, прогнозування, оцінювання моделі та бізнес‑інтерпретацію.

# **Дані**

* **Джерело:** навчальний датасет для курсу з Data Analytics / Machine Learning.  
* Місячні доходи з січня 2022 до грудня 2024 (36 спостережень).  
* Змінні:  
  * `month_number`  
  * `year`  
  * `month`  
  * `month_name`  
  * `revenue`

# **Мета проєкту**

Розробити модель машинного навчання для прогнозування майбутніх місячних доходів на основі історичних даних продажів та інтерпретувати результати з бізнесової точки зору.

# **Кроки проєкту**

1. Підготовка та дослідження даних.  
2. Проведення експлораторного аналізу даних.  
3. Створення тренувального набору.  
4. Тренування лінійної регресійної моделі за допомогою scikit‑learn.  
5. Прогнозування майбутніх місячних доходів.  
6. Бізнес‑інтерпретація результатів.

# **Технології**

* Python  
* Pandas  
* NumPy  
* Matplotlib  
* Scikit‑learn  
* Jupyter Notebook / Google Colab

# **Основні висновки**

* Місячний дохід демонструє чітку висхідну тенденцію.  
* Лінійна регресія надійно відображає загальний тренд.  
* Модель підходить як основа для простих прогнозів доходу.
